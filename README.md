# Intelligent AI Lead Qualification and Management Agent

## Project Overview
An AI-powered lead management application that automates lead qualification, scoring, categorization, and personalized follow-up email generation.

## Technologies Used
- Python
- Google Gemini API
- Pandas
- SQLite
- Streamlit
- Google Colab
- Pyngrok

## Key Features
- Lead information collection
- AI-powered lead qualification
- Lead scoring and categorization (Hot, Warm, Cold)
- SQLite database storage
- Interactive Streamlit dashboard
- AI-generated follow-up emails

## Project Workflow
1. Collect lead details.
2. Analyze leads using Google Gemini.
3. Generate qualification reports and scores.
4. Store lead information in SQLite.
5. Display results in the Streamlit dashboard.
6. Generate and store personalized follow-up emails.

## Project Files
- `Intelligent_AI_Lead_Qualification_Agent.ipynb` – Complete project implementation.
- `AI OPPORTUNITY REPORT.docx` – Industry analysis and selected AI opportunity.
- `TECHNICAL APPROACH REPORT.docx` – Technical architecture and execution plan.

## Setup
1. Install the required Python libraries.
2. Configure your Gemini API key securely.
3. Run the notebook in Google Colab.
4. Start the Streamlit application.

## Security
API keys and authentication tokens should be stored securely using environment variables or Colab Secrets. Never commit credentials to GitHub.
